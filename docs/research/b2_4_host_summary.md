# B2.4 — сводка и сравнение хостов одного отчёта

Уточнение к B1 §3.3. Сводка вычисляется при чтении сохранённого отчёта из `results` и `execution_context`; отдельной таблицы и изменения старого формата отчёта нет. Группировка только по `execution_context[*].host`, а не по имени ключа `by_host` (`h#2` — ключ второго экземпляра, но имя хоста остаётся `h`). Порядок хостов и проверок — порядок первого появления в отчёте.

`host_summary(report)` возвращает по одной строке на хост: `completed_checks`, `errored_checks`, наблюдённые количества проблем `critical/high/medium/low` либо `null`, и массивы `error_checks`, `incomplete_checks`, `unknown_checks`, `duplicate_checks`. В `checks` хранятся `check_id`, `instance_key`, `status`, наблюдённые количества или `null`; сырой результат, error-текст, предупреждения и параметры, в том числе секреты, в сводку не копируются. `details_url` добавляется только API при известном ID отчёта и ведёт к сохранённому отчёту. Нулевые наблюдённые количества означают лишь, что в понятной форме результата проблем не обнаружено; интерфейс не называет хост безопасным.

Статусы проверки: `error` при непустом `error`; `incomplete` при непустом `warnings` или finding с `requires_manual_verification` любой severity; `unknown` при форме без сопоставимых findings; иначе `complete`. Findings читаются через `trends._scoped_findings()`, где плоская форма имеет приоритет перед секциями и finding не учитывается дважды. Для `error` и `unknown` количества `null`. У `incomplete` известные findings считаются наблюдёнными, но сбор не считается полным. Если один host встречается более одного раза для того же check, каждый экземпляр виден отдельно в сравнении, а сводная строка помечает проверку `duplicate_checks` и не складывает количества таких экземпляров — объединение неоднозначно.

`compare_hosts(report, check_id)` показывает только экземпляры **одного** check текущего отчёта в порядке входа: имя host, ключ экземпляра, статус, наблюдённые количества. Разности между разными checks и вывод об исправленных отсутствующих findings не вычисляются. CLI и Web читают тот же модуль без AI.
